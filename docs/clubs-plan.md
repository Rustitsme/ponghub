# PongHub → платформа клубов (план, решения владельца от 16.10.2026)

## Решения владельца
1. **Аккаунт отдельно от клуба.** Регистрация создаёт только аккаунт (без одобрения на уровне платформы). Дальше человек:
   - создаёт свой клуб → сразу становится его **владельцем**;
   - или вступает в клуб: **по приглашению** (ссылка/код — вход сразу) или **по заявке** (нашёл клуб поиском → владелец одобряет).
2. **Любой может создать клуб бесплатно.** Первый (создатель) — владелец со всеми правами.
3. **Передача прав владельца** другому участнику клуба (уход, обстоятельства).
4. **Сколько угодно клубов** у одного человека; в каждый — только через одобрение или приглашение.
5. **Поиск клуба** по названию или по ID клуба (короткий код вида PH-7K2Q).
6. **Карта клубов**: отдельный раздел, клубы на карте; по нажатию — страница клуба: игроки, места в рейтинге, сыгранные игры (всё, что есть сейчас, только просмотр).
7. Общий межклубный рейтинг игроков пока **не нужен** (вопрос снят).
8. Текущий коворкинг → **клуб №1** со всеми игроками, матчами, рейтингом, пинг-коинами; владелец — Рустам. Людям ничего делать не нужно.

## Роли
- **Владелец платформы** (Рустам): видит все клубы, может блокировать спам/фейки.
- **Владелец клуба**: всё внутри своего клуба (как сейчас владелец): заявки, подтверждения, турниры, календарь, журнал, настройки рейтинга, тест, объявления, помощники, передача владения.
- **Помощник клуба**: вносит результаты своих матчей (сразу засчитаны).
- **Игрок клуба**: вносит свои результаты на подтверждение.
Роли — **на уровне членства в клубе** (в одном клубе владелец, в другом игрок).

## Этапы
1. **База**: таблицы `clubs` (название, код, город, адрес, координаты, описание, логотип, видимость) и `club_members` (роль, статус); `club_id` во всех таблицах (matches, tournaments, events, challenges, live_matches, announcements, pred_events, predictions, coin_tx, audit_log, settings → настройки на клуб); перенос текущих данных в клуб №1; новые правила доступа (RLS) через `is_member(club)`, `is_club_admin(club)`; все RPC/триггеры с учётом клуба; уведомления — только участникам клуба.
2. **Приложение**: текущий клуб + переключатель; экран «нет клуба» (создать / вступить по коду / найти); создание клуба (название, город, точка на карте); приглашение (ссылка + код), вход по ссылке; заявки в клуб; передача владения; все экраны работают в рамках выбранного клуба.
3. **Витрина**: карта клубов (Leaflet + OpenStreetMap, бесплатно), список/поиск, публичная страница клуба (игроки, рейтинг, число игр), кнопка «Подать заявку».
4. **Платформа**: панель владельца платформы (все клубы, блокировка).

Потом: магазины (RuStore/GetApps), подписка «Организатор» для владельцев клубов.

## Технические заметки
- Пинг-коины — **отдельно в каждом клубе** (coin_tx.club_id), прогнозы только внутри клуба.
- Рейтинг считается по матчам клуба, система рейтинга — настройка клуба.
- Публичная страница клуба доступна зарегистрированным пользователям; без email и личных данных.
- Карта: клуб ставит точку на карте при создании (без платных геокодеров); поиск адреса — Nominatim (бесплатный, с ограничением частоты).
