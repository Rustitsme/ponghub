# 🏓 PongHub — пинг-понг в коворкинге

Приложение для нашего коворкинга: учёт матчей, рейтинг, турниры и личная статистика.
Устанавливается на телефон по ссылке, без App Store и Google Play.

## Возможности

- **Регистрация с подтверждением.** Любой может подать заявку, но в клуб человек попадает только после одобрения владельцем.
- **Роли.** Владелец (админ), **помощники** (могут вносить результаты и вести турниры, права включаются и выключаются в любой момент) и игроки (только смотрят и могут отправить свой результат на подтверждение).
- **Рейтинг по системе Эло**, адаптированный под любительскую шкалу (старт 40). Стартовый рейтинг можно задать каждому игроку отдельно.
- **Свободные игры и турнирные матчи.** Турнирные весят больше.
- **Любой формат:** до 1, 2, 3 или 4 побед в партиях; партия до 11, до 21 или до своего числа очков. Можно ввести счёт каждой партии или только итог.
- **Турниры:** олимпийская система (сетка с посевом по рейтингу и матчем за 3-е место), круговой турнир, группы + плей-офф.
- **Статистика игрока:** график рейтинга, форма, серии, лиги, медали, 15 достижений, анализ слабых мест с подсказками.
- **Личные встречи** любых двух игроков и шанс победы по рейтингу.
- **Игрок месяца**, календарь игр с отметкой «Иду», живые обновления во время турнира.
- **Выгрузка** рейтинга и матчей в Excel и полная резервная копия.
- **Фото профиля** — каждый может загрузить свою фотографию (или выбрать эмодзи).
- **Push-уведомления**: новые матчи, заявки, турниры, события календаря.
- **Парные игры 2×2** с отдельным парным рейтингом (можно не учитывать игру в рейтинге).
- **Вызов на матч** с уведомлениями, **сезоны** (чемпион месяца), **итоги недели** по понедельникам, **карточка результата** для мессенджеров.
- **Снижение рейтинга без игр** (после 30 дней, не ниже стартового).
- **Журнал изменений** для владельца: удаление только с причиной, восстановление удалённых матчей, уведомление владельцу об удалениях.
- **Автоматическая резервная копия** каждый понедельник (12 последних), **защита от «засыпания» базы** (ежедневная проверка через Vercel Cron).
- Две иконки приложения на выбор (Управление → Рейтинг), светлая и тёмная темы. Работает на iPhone, Android и компьютере.

## Как считается рейтинг

```
Шанс победы = 1 / (1 + 10^((Рсоперника − Рмой) / 50))
Изменение    = K × (Результат − Шанс) × коэффициент счёта × бонус новичка
```

- K = **8** для турнира и **4** для свободной игры.
- Коэффициент счёта: 3:0 → ×1.1, 3:1 → ×1.0, 3:2 → ×0.9.
- Бонус новичка: первые 10 матчей ×1.5.

Примеры для турнира (3:1): победа над игроком на 30 очков сильнее даёт **+6.4**, поражение ему же **−1.6**, победа над равным **+4**.
Все коэффициенты меняются в приложении: Профиль → Управление → Рейтинг. После изменения вся история пересчитывается.

## Подключение базы (один раз, около 10 минут)

Пока база не подключена, приложение работает в **демо-режиме** с выдуманными игроками.

### 1. Создайте проект в Supabase (бесплатно)
1. Зайдите на [supabase.com](https://supabase.com) и войдите через GitHub.
2. Нажмите **New project**, задайте имя `ponghub`, придумайте пароль базы и выберите регион **Central EU (Frankfurt)**.
3. Подождите 1–2 минуты, пока проект создаётся.

### 2. Создайте таблицы
1. Слева откройте **SQL Editor** → **New query**.
2. Скопируйте туда всё содержимое файла [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**. Должно появиться «Success».

### 3. Настройте вход
1. **Authentication → Sign In / Providers → Email**: выключите **Confirm email**. Подтверждать людей будете вы сами в приложении, поэтому письма не нужны.
2. **Authentication → URL Configuration → Site URL**: укажите адрес приложения, например `https://ponghub-club.vercel.app/`.

### 4. Пропишите ключи в приложении
1. **Project Settings → API**: скопируйте **Project URL** и ключ **anon / public** (или **Publishable key**).
2. Вставьте их в файл [`js/config.js`](js/config.js):
   ```js
   export const CONFIG = {
     SUPABASE_URL: 'https://xxxx.supabase.co',
     SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   };
   ```
   Этот ключ публичный по задумке Supabase: доступ к данным защищён правилами в базе, а не секретностью ключа.
3. Сохраните и отправьте изменения на GitHub.

### 5. Включите push-уведомления
1. **Edge Functions → Deploy a new function → Via Editor**, имя функции — `notify`.
2. Вставьте содержимое файла [`supabase/functions/notify/index.ts`](supabase/functions/notify/index.ts) и нажмите **Deploy**.
3. В настройках функции выключите **Verify JWT** (база вызывает её без токена; вместо этого функция проверяет свой секрет).

Ключи для уведомлений функция создаёт сама при первом запуске — ничего вписывать не нужно.
На iPhone уведомления работают в приложении, установленном на экран «Домой» (iOS 16.4+).

### 6. Зарегистрируйтесь первым
**Первый зарегистрированный пользователь автоматически становится владельцем клуба.** Откройте приложение, зарегистрируйтесь, и только потом отправляйте ссылку друзьям.

## Как раздать приложение

Отправьте ссылку `https://ponghub-club.vercel.app/` в чат.

- **iPhone:** откройте в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте в Chrome → меню ⋮ → «Установить приложение».

Обновления приходят сами: достаточно отправить изменения на GitHub.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html`, `css/style.css` | Оформление |
| `js/app.js` | Экраны и логика интерфейса |
| `js/engine.js` | Расчёт рейтинга, статистика, достижения |
| `js/tourney.js` | Сетки и таблицы турниров |
| `js/store.js` | Работа с базой и демо-режим |
| `supabase/schema.sql` | Таблицы, права доступа, хранилище фото, триггеры уведомлений |
| `supabase/functions/notify` | Рассылка push-уведомлений |

## Для разработчика

- Обновления базы: `supabase/migration-002-*.sql`, `supabase/migration-003-*.sql` (уже применены; `schema.sql` содержит всё для новой установки).
- `supabase/functions/notify/engine.js` — **копия** `js/engine.js`. Меняя движок рейтинга, обновите копию и переразверните функцию.
- Расписание (pg_cron, UTC): итоги недели — пн 07:00, итоги сезона — 1-го числа 07:00, резервная копия — пн 02:00.
